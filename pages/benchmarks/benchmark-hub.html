Visual Color Blending & Execution Trace Benchmark

Overview

This tool renders a 400 × 400 pixel gradient matrix (160,000 pixels) on four separate canvases, performing real-time blending on each pixel. Observe the rendering speed difference.

1. Visual Benchmark Methods

Conventional Method Unaligned #6B7280

Computes blending with float division and Math.round on each pixel.

// Pixel loop blend calculation
r = Math.round((c1.r * weight + c2.r * (255 - weight)) / 255);
// (Requires register division and rounding)
-- ms

Optimized Method Aligned #808080

Computes blending using binary shift (>> 1) on aligned boundaries.

// Pixel loop blend calculation
r = (c1.r >> 1) + (c2.r >> 1);
// (Single-pass bit-shift execution)
-- ms

Ultimate SWAR Packed 32-bit

Computes parallel R+B channel blending in a single SIMD-like register.

// Packed pixel blend calculation
rb = (prod + ((prod>>8)&0x00FF00FF))>>8;
// (Parallel execution with 0% overlap)
-- ms

SWAR + Uint32 Absolute Fastest

SWAR blend + single 32-bit word write via Uint32Array view.

// 1-write pixel output
uint32[i] = (0xFF000000|b<<16|g<<8|r) >>> 0;
// (4 byte writes ↁE1 word write)
-- ms
