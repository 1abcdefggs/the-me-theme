# TheMeTheme

**TheMeTheme** is a highly accurate, visual, and real-time color theme studio for Visual Studio Code.


https://github.com/user-attachments/assets/159a29bd-f75a-429f-8fce-b9d8a252545f


## Concept: "The Me Theme"
Why *TheMeTheme*?
If you break down the word **"Theme"**, you get **"The Me"**. 
A theme is not just a configuration file; it is an expression of yourself. **TheMeTheme** is designed to help you build "The Me" into your code, allowing you to visually design and craft the ultimate theme that reflects your unique style.

## Features
- **Visual Editor (Studio)**: A highly accurate, interactive Mock UI of VS Code. See your color changes reflected instantly in the browser without needing to export or reload.
- **Source of Truth Reference**: Powered by a direct extraction of over 900+ actual color variables from the active VS Code source code repository. No more guessing what `editor.background` does.
- **Precision Styling**: Search, filter, and modify tokens with granular control.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and start crafting your "The Me" theme!

## Build
```bash
npm run build
```
